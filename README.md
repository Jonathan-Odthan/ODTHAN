# ODTHAN — Site web

## Installation
1. Décompresser le dossier.
2. Ouvrir `index.html` dans un navigateur.
3. Pour une mise en ligne, téléverser tout le dossier sur votre hébergement.

## Structure
- `index.html` : accueil
- `pages/about.html` : à propos
- `pages/services.html` : services
- `pages/investissement.html` : investissement
- `pages/commercialisation.html` : commercialisation
- `pages/contact.html` : contact
- `assets/css/style.css` : design noir/or
- `assets/js/main.js` : interactions

## À personnaliser
- Logo réel dans `assets/images/`
- Téléphone et email
- Réseaux sociaux
- Adresse
- Informations légales
- Conditions d'investissement

La page investissement utilise 25 000 HTG comme exemple et ne présente pas de rendement garanti.
